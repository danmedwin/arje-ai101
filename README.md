# AI 101 for Jewish Educators

Single-file webpage of resources from Rabbi Dan Medwin's "AI 101 for Jewish Educators" session at ARJE, January 26, 2027: how to start, eight practice steps (Na'aseh v'Nishma), four concerns through Jewish values, and starter prompts for building classroom mini-apps.

Live at techrabbi.org/arje-ai101

- `index.html` is the whole page. Prompts live in the `LANE`, `STARTERS`, and `REVISIONS` lists near the bottom.
- `img/` holds the example screenshots.
- `examples/` holds two of the example mini-apps (Jewish Journeys and Israel Cities Map).

Built with Claude, an AI assistant made by Anthropic. Rabbi Dan Medwin set the direction and is responsible for the content.
